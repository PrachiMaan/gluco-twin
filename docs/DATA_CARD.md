# Data card: GlucoTwin synthetic cohort

## What this dataset is

GlucoTwin ships with 1,500 synthetic patients. No row comes from a real person,
a hospital record, or a downloaded clinical dataset. The cohort is generated by
two scripts in this repository:

- `src/ehr_gen.py` writes `data/ehr.csv` (one row per patient) and
  `data/manifest.json`.
- `src/cgm_sim.py` reads that table and writes `data/cgm.npz` (5-minute
  glucose, heart rate, HRV, steps and sleep stage) plus
  `data/true_params.csv` (the physiological parameters used for the
  simulation) and `data/sim_manifest.json`.

Both scripts use fixed seeds (42). Re-running them on the pinned versions in
`requirements.txt` reproduces the same files byte for byte.

The generator follows the spirit of Synthea (open-source synthetic patients),
but it is a custom generator written for this project. It is not Synthea and it
is not validated against any real cohort.

## Size

| Item | Value |
| --- | --- |
| Patients | 1,500 |
| Days per patient | 14 |
| Sampling interval | 5 minutes |
| Steps per patient | 4,032 |
| Glucose readings | 6,048,000 (1.5% missing by design) |
| Cohort mean HbA1c | 7.1% |
| Cohort mean age | 55.8 years |
| Cohort mean BMI | 24.8 kg/m2 |
| Mean 14-day glucose | 167.3 mg/dL |
| Share of readings above 180 mg/dL | 23.5% |
| Share of readings below 70 mg/dL | 0.05% |
| Event base rate (2-hour label) | 41.1% |

The high mean glucose is intentional. An uncontrolled T2D cohort produces
enough hyperglycemic events to train and evaluate a 2-hour warning model. A
well-controlled cohort would have almost no positive labels. This also means
the cohort is **not** representative of average primary-care diabetes in India,
where a larger share of patients sits between 7% and 8% HbA1c.

## Every distribution assumption

### Demographics and body shape

| Field | Assumption | Why |
| --- | --- | --- |
| `age` | Normal(56, 9.5), clipped to 30-79, then raised so age at diagnosis is at least 25 | Indian T2D onset is earlier than in Western cohorts; the clinic population in the summit brief is middle-aged |
| `sex` | 56% male | Roughly the sex mix reported in Indian T2D clinic series |
| `bmi` | Normal(24.8, 3.6), clipped to 16.5-42.0 | Indian T2D presents at a lower BMI than Western cohorts (the "lean Indian" phenotype) |
| `waist_cm` | Male base 89.5, female base 83.0, plus 1.18 x (BMI - 22), plus Normal(0, 4), clipped to 68-135 | Central adiposity is high relative to BMI; waist is deliberately not a simple linear function of BMI alone |
| `diet_type` | 42% vegetarian | Common Indian dietary pattern; used as a static feature only |
| `family_history` | 35% positive | Family history is common in T2D and is a standard intake field |

### Disease history and genetics

| Field | Assumption | Why |
| --- | --- | --- |
| `years_since_dx` | Normal(6.2, 5.0), clipped to 0-30 | Mixed newly diagnosed and long-standing patients |
| `tcf7l2` | CC 65%, CT 30%, TT 5% (T allele frequency 0.20) | Approximates Hardy-Weinberg with a T allele frequency of 0.2, a common assumption for rs7903146 in South Asian populations. It is a modelling assumption, not a measured frequency |
| Genetic risk dose | TT +0.55 HbA1c points, CT +0.20, CC 0 | Direction and rough size follow the published rs7903146 association; the exact effect size is illustrative |
| `prior_hypo_count` | Poisson with lambda = 0.20 + 1.10 x sulfonylurea + 1.70 x insulin + 0.04 x years_since_dx + 0.35 if HbA1c < 7.0, clipped to 0-15 | Hypoglycemia is driven mainly by sulfonylureas and insulin, and is more common in tightly controlled patients |

### Laboratory values

| Field | Assumption |
| --- | --- |
| `hba1c` | 6.75 + 0.040 x years_since_dx + 0.050 x (BMI - 24) + 0.020 x (age - 55) + genetic dose + Normal(0, 0.85), clipped to 5.4-13.0 |
| `fpg_mgdl` | 0.72 x eAG + 32 + Normal(0, 8), clipped to 70-300, where eAG = 28.7 x HbA1c - 46.7 (the ADAG conversion) |
| `triglycerides` | Log-normal with median 145, 0.032 log-points per BMI unit, 0.015 per year since diagnosis, sigma 0.38, clipped to 50-650 |
| `ldl` | 112 + 0.45 x (BMI - 24) + Normal(0, 27), clipped to 45-210 |
| `systolic_bp` | 124 + 0.44 x (age - 50) + 0.38 x (BMI - 24) + 0.28 x years_since_dx + Normal(0, 12), clipped to 95-195 |
| `hypertension` | Logistic(-0.25 + 0.055 x (SBP - 132) + 0.045 x (age - 55) + 0.06 x (BMI - 24)); prevalence 41.9% |
| `egfr` | 106 - 0.62 x (age - 45) - 0.9 x years_since_dx - 6 x hypertension + Normal(0, 10), clipped to 20-135 |

These formulas create the correlations the brief asks for: HbA1c rises with
fasting glucose through eAG, BMI raises triglycerides and LDL, and albuminuria
is not modelled at all (a known gap).

### Medications

Prevalence in the generated cohort: metformin 89.7%, sulfonylurea 43.5%,
DPP-4 inhibitor 19.6%, insulin 9.5%.

| Drug | Probability model |
| --- | --- |
| Metformin | Logistic(2.0 + 1.0 x (HbA1c - 7) + 0.05 x years_since_dx - 0.02 x (eGFR - 90)) |
| Sulfonylurea | Logistic(-0.8 + 0.7 x (HbA1c - 7) + 0.06 x years_since_dx) |
| DPP-4 inhibitor | Logistic(-1.7 + 0.5 x (HbA1c - 7.5) + 0.08 x years_since_dx) |
| Insulin | Logistic(-2.2 + 1.3 x (HbA1c - 8) + 0.09 x years_since_dx) |

The eGFR term in the metformin equation reflects the real prescribing rule that
metformin is used with caution in reduced kidney function. SGLT2 inhibitors and
GLP-1 receptor agonists are not modelled, which is a real limitation for a 2026
Indian cohort where both are increasingly common.

## Glucose and wearable simulation

The glucose model is a meal-absorption plus insulin-sensitivity model in the
style of the Bergman minimal model:

```
dG/dt = -(G - Gbasal) / tau_g
        + dawn(t)
        + Ra(t)                 meal appearance (mg/dL per minute)
        + stress(t)
        + rescue(t)             counter-regulation below 70 mg/dL
        - s_i_eff * (X + Xe - X0 - Xe_basal) * max(G - 55, 0)
```

`X` is a delayed endogenous insulin-action compartment (time constant 26 min,
15-minute sensing delay), `Xe` is exogenous insulin action for insulin users
(time constant 45 min), and `s_i_eff` is insulin sensitivity modified by sleep
and post-meal walking.

| Parameter | Derivation from the EHR |
| --- | --- |
| Basal glucose `g_basal` | FPG - 4 + Normal(0, 5) |
| Insulin sensitivity `s_i` | 0.033 x exp(-0.065 x (BMI - 22) - 0.030 x years_since_dx - 0.085 x (HbA1c - 7)) x metformin and DPP-4 multipliers x log-normal jitter, clipped to 0.004-0.12 |
| Glucose time constant `tau_g` | 60 + 0.8 x (BMI - 22) + 0.6 x years_since_dx + Normal(0, 5), clipped to 45-110 min |
| Secretion gain `x_gain` | 3.0 - 0.09 x years_since_dx - 1.1 x TT - 0.4 x CT + HbA1c term, then reduced 40% on insulin and raised 35% on sulfonylurea, clipped to 1.0-4.0 |

Carbohydrate appearance uses a gamma-shaped absorption curve,
`amp * k^2 * t * exp(-k t)`, with 2.0 mg/dL of glucose appearance per gram of
carbohydrate and meal-specific absorption rates (breakfast 0.024, rice 0.028,
roti 0.021, snack 0.031, sweets 0.035, dinner 0.023 per minute).

### Meals

| Meal | Time | Carbs | Notes |
| --- | --- | --- | --- |
| Breakfast | 07:00 +/- 25 min | 45-70 g | |
| Lunch | 12:50 +/- 30 min | 70-110 g | 60% rice-based, 40% roti-based |
| Snack | 16:40 +/- 30 min | 12-25 g | 80% of days |
| Dinner | 20:35 +/- 30 min | 55-90 g | 70% mixed dinner, 30% roti |
| Late snack | 22:40 +/- 15 min | 15-30 g | 12% of days |
| Festival day | one day between 8 and 10, 50% of patients | all meals x 1.45 plus 35-55 g sweets at 18:00 | Models a festival or celebration day |

### Activity, sleep, stress

| Signal | Assumption |
| --- | --- |
| Morning walk | 55% of patients, 06:50, about 30 min |
| Post-lunch walk | 35% of patients, 13:55, about 20 min |
| Post-dinner walk | 40% of patients, 21:20, about 28 min |
| Formal exercise | 18% of patients, 30 min between 18:00 and 19:30 |
| Walking effect | insulin sensitivity +90% during the walk, decaying with a 0.94 per 5-minute factor after it ends (roughly 2 hours of residual effect) |
| Sleep window | bed 22:45 +/- 35 min (45 min later on weekends), wake 06:15 +/- 30 min |
| Poor sleeper | logistic(-1.0 + 0.10 x (BMI - 24) + 0.03 x (age - 55)) |
| Sleep effect | next-day insulin sensitivity multiplier clip(1 + 0.022 x (sleep hours - 7), 0.86, 1.08) |
| Sleep stages | 90-minute cycles of light, deep and REM, with awake periods proportional to (1 - quality) |
| Daily stress | Beta(2, 5), plus 0.2 on a festival day, with a 1.3 multiplier during 10:00-18:00 |
| Stress effect | up to 0.12 mg/dL per minute at stress level 1.0 |

### Sensor artefacts

| Artefact | Assumption |
| --- | --- |
| CGM noise | Normal(0, 4.5) mg/dL |
| Drift | Normal(0, 0.003) mg/dL per step |
| Dropouts | 2 to 4 gaps of 30 to 180 minutes per patient over 14 days, 1.5% of readings missing |
| Range | clipped to 40-450 mg/dL |
| Heart rate | resting 64 + 0.28 x (BMI - 24) + 0.18 x (age - 55) + Normal(0, 5), plus 0.075 per step, plus a glucose term, minus 8 at night, plus Normal(0, 2.5) |
| HRV (RMSSD) | base 38 - 0.55 x (BMI - 24) - 0.35 x years_since_dx + Normal(0, 9), raised 35% at night, reduced by high heart rate, recent hyperglycemia and stress |
| Steps | individual walk blocks plus a background activity level that is higher at weekends and lower at night |

## EHR to CGM linkage

The linkage is structural, not cosmetic: every physiological parameter is a
function of that patient's own EHR fields. A patient with a high fasting glucose
starts from a higher basal set point. A patient with a long duration, high BMI
and high HbA1c has lower insulin sensitivity and a slower meal return. A TT
genotype at TCF7L2 reduces the secretion gain. The tests in
`tests/test_data.py` check that patients with worse glycemic control have
higher mean simulated glucose, and that the ordering is stable.

The inverse problem is also checked. `src/twin.py` fits each patient's
`s_i`, `g_basal` and `tau_g` from the CGM series alone. On held-out patients the
fit recovers `s_i` with R2 0.82, median absolute percentage error 8.4% and
Spearman correlation 0.91 against the simulator's true values
(`results/param_recovery.json`). This is a check that the twin's fitting
procedure works on data where the answer is known. It is not evidence that the
same fit works on real patients.

## Privacy and ethics

- No real patient data was used at any point.
- No field is derived from a real person, so there is no re-identification risk
  from this dataset.
- In a real deployment under India's Digital Personal Data Protection (DPDP)
  Act, 2023, CGM and wearable data would be personal health data. A production
  system would need purpose limitation, consent, a data-fiduciary agreement,
  breach notification and data-principal rights. HIPAA is the corresponding US
  framework. This repository is designed with those requirements in mind
  (synthetic-only development, no third-party transmission), but it is not
  certified for either.
- The cohort over-represents uncontrolled diabetes and under-represents kidney
  disease, SGLT2/GLP-1 use, and patients above 79. A model trained on it should
  not be read as a statement about the Indian diabetes population.
