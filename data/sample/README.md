# Sample data

Three synthetic patients, first day only, cut from the full generated
cohort by `python src/make_sample.py`. The full dataset is regenerated by
`make data` and is not committed. See `docs/DATA_CARD.md` for every
distribution assumption.

- `ehr_sample.csv`: 3 rows, the same columns as `data/ehr.csv`
- `cgm_sample.npz`: 288 steps at 5 minutes (24 hours) per patient
  with glucose, heart rate, HRV, steps and sleep stage

Glucose uses -1 for missing readings. HRV is stored in tenths of a
millisecond (divide by 10).

Generator seed: 42
